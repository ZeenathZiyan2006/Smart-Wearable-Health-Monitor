# Smart-Wearable-Health-Monitor
An IoT-based wearable health-monitoring device designed to track vital health parameters such as heart rate, SpO2, body temperature, sleep patterns, and physical activity in real time.
Smart Wearable Health Monitor

About the Project

Smart Wearable Health Monitor is an IoT-based wearable device designed to monitor and track various health parameters in real time.

Objectives

- Monitor heart rate.
- Estimate blood oxygen levels (SpO2).
- Monitor skin temperature.
- Track physical activity and steps.
- Monitor sleep patterns.
- Provide emergency alerts.

Technologies Used

- ESP32
- MAX30102
- MPU6050
- Python
- Flutter
- Firebase

Project Architecture

Wearable Device → Sensors → ESP32 → Cloud Database → Mobile Application

Features

- Real-time health monitoring
- Health data visualization
- Activity tracking
- Emergency notifications
